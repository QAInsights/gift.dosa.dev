# Impeccable

Project design memory for AI-assisted frontend work.

## Design Context

### Users

Solo-builder hackathon app for the Meta Global AI Developer Hackathon (indie track: judged on creativity, technical ambition, and whether it works). End users are members, students, and professionals tracking gift-card balances; judges will demo it from a fresh account. Context: mobile and desktop, quick photo capture plus glanceable balances and reminders.

### Brand Personality

Professional with a playful streak. Three words: trustworthy, warm, delightful. The interface should evoke confidence (money is safe here), delight (gifts are joyful), and calm (everything in its place). Playfulness lives in details, empty states, and celebrations — never in security, money, or error moments. Working brand: Gift Cabinet (gift.dosa.dev).

### Aesthetic Direction

"Letterpress Luxe" (locked): ivory stock, espresso ink, gold foil actions, oxblood seals, teal calm. Fraunces display, Figtree UI, Plex Mono figures; one Lucide icon sprite; motion only for state changes. Light-first; dark deferred. Explicit anti-references: generic fintech dashboard, dark neon AI aesthetic, purple-blue gradients, gradient text, emoji icons, untracked-cap kickers.

### Design Principles

1. **Paper before pixels.** Warm tinted surfaces, engraved-plate card tiles, and foil details — it should feel like a beautiful physical cabinet, not a dashboard template.
2. **One foil moment per surface.** Gold is a seal, not paint: a single foil CTA or accent per viewport keeps it precious.
3. **Editorial rhythm, not grids.** Asymmetric composition, varied spacing, left-aligned type; the cabinet grid is the one place repetition is allowed, broken by a spotlight tile.
4. **Trust is visible.** Vault items look sealed (seal, mask, lock gate); sensitive data is masked by default and never decorative.
5. **Motion means state.** Flip to reveal, slide to open, burst only to celebrate — every animation maps to a state change, and all of it yields to reduced-motion.
