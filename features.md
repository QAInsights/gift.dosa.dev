Users should be able to sign up and sign in with email and OTP.
Users should be able to update their profile information.


Cabinet:
Cabinet is a collection of gift cards with/without pin.

- Users should be able to add cards to their cabinet
- Users should be able to remove cards from their cabinet
- Users should be able to view their cabinet
- Users should be able to view their cabinet stats
- Users should be able to view their cabinet items
- Users should be able to view their cabinet items in a grid view
- Users should be able to view their cabinet items in a list view
- Users should be able to search their cabinet items
- Users should be able to filter their cabinet items
- Users should be able to sort their cabinet items
- Users should be able to view their cabinet items in a detail view
- Users should be able to customize their cabinet with color, pattern/background
- Subtle animation is important for a better user experience like opening/closing

Memories:
- Some gift cards not to be deleted or use because users must have a close connection with the person who gave them
- Users should be able to mark gift cards as memories
- Users should be able to view their memories in a separate view

Gift Cards:
- Users should be able to add/edit/remove gift cards with/without pin
- Each gift card should display their store icon/logo
- Each gift card should display their balance
- Each gift card should display their expiry date
- Each gift card should display their pin (if available)
- Each gift card should display their status (active, expired, etc.)
- Each gift card should display their notes and tags
- Each gift card should have an occasion field (birthday, anniversary, etc.)
- Users should be able to customize their gift cards with color, pattern/background
- Subtle animation is important for a better user experience like opening/closing
- Users should be able to set reminders for gift cards

Home page view:
- It should display the gift card value, stats, and recent activity in a beautiful and intuitive way.

WhatsApp integration:
- Users should be able to add/edit/view/scan gift cards via WhatsApp

AI Features
- AI powered search in natural language
- Gift card recommendation based on occasion
