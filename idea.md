# gift.dosa.dev

We are going to build a web application for the hackathon. Users will be able to add their gift‑card details, such as the retailer name, amount, remaining balance, occasion, metadata, and tags. They can configure reminders and view the total balance on a dashboard, as well as categorize the gift cards.

The application should map the real‑life experience of storing gift cards. I have a Cloudflare Pro account, so we can use it for the backend. The app should support simple sign‑in and sign‑up with email and a one‑time password, and it must be responsive. Users should be able to store hundreds of cards for free and create a cabinet‑like folder structure to display them.

All gift‑card data must be securely stored with encryption at rest and in transit. We can add a locking feature that requires a password to unlock a particular folder or cabinet, providing an extra layer of security.

For reminders, we can use email notifications via Cloudflare email subscriptions. The application will be hosted under a .dev domain.

The homepage should include information about how people forget to use gift cards, statistics about the gift‑card industry, and the current state of the market for members, students, and professionals. This is a high‑level overview; we can improve the design as we begin building the application.
